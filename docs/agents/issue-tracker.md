# Issue Tracker

This repo uses GitHub Issues as the issue tracker.

- Repository: `tannerpolley/superpowers-project`
- Issue source of truth: GitHub Issues. Local mirrors under `docs/superpowers/issues/` exist only while an issue is executable or explicitly retained.
- GitHub Milestones are the milestone tracking source. Local milestone pages are temporary working views or runtime receipts.
- GitHub parent/sub-issue links carry optional grouped-work hierarchy.
- Parent issue labels such as `type:issue-set`, `type:sub-milestone`, and `type:plan-wrapper` identify rollup records; executable implementation work stays on leaf issues.
- GitHub Projects are dashboard evidence only unless future repo config makes them mandatory.
