# Issue Tracker

This repo uses GitHub Issues as the issue tracker.

- Repository: `tannerpolley/milestones-plugin`
- Issue source of truth: GitHub Issues plus synced local issue files under `docs/milestones/<milestone-folder>/issues/`.
- Milestones are hard workflow buckets and mirror `docs/milestones/PROJECT_CONTEXT.md`.
- GitHub Projects are dashboard evidence only unless future repo config makes them mandatory.
