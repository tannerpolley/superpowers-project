# Agent-Native Companion Replacement

<Callout id="decision-agent-native-mdx" tone="decision">

Replace the Superpowers Project static HTML companion with repo-owned Agent-Native Plan MDX. The review artifact lives under `plans/<slug>/`; native Codex chat and `request_user_input` remain the approval channel.

</Callout>

## Concrete Review Snapshot

During a future `brainstorm-spec` run, the agent writes the canonical spec under `docs/superpowers/specs/`, then creates `plans/<slug>/plan.mdx` as the rich review surface. The user opens the local Agent-Native preview, scans evidence, diagrams, file maps, and validation receipts, then answers the normal native `Continue?` gate in Codex. No browser control inside the plan records approval.

## Done Criteria

- `skills/companion-interface` describes Agent-Native MDX visual-plan artifacts instead of static HTML reports.
- HTML report-session scripts, templates, and active tests are removed or rewritten; no pass-through wrapper remains.
- README, plugin prompt, project context, and related skill opt-in text point to visual-plan MDX.
- A fixture local plan under `plans/<slug>/plan.mdx` previews with Agent-Native local-files mode.
- Full repo validation, live sync validation, and cleanup proof pass.

## Validation

The first implementation plan should prove the replacement with focused tests before broad validation:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\test-companion-interface.ps1
npx @agent-native/core@latest plan local preview --dir plans/fixture-agent-native-companion --kind plan --open
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\validate.ps1
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\sync-live.ps1 -Validate
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\.codex\hooks\codex-cleanup.ps1" -RepoRoot .
```

## Risks

<Callout id="risk-hosted-tools" tone="risk">

Hosted Plan MCP absence must not block the repo-owned path. If hosted tools are missing, use local-files mode. If local preview fails, report the exact command and error instead of inventing a URL or substituting HTML.

</Callout>

<Callout id="risk-source-roots" tone="warning">

`plans/<slug>/plan.mdx` is the Agent-Native review artifact root. It does not replace canonical Superpowers implementation plans under `docs/superpowers/plans/`.

</Callout>

## Open Questions

No blocking decisions remain for the replacement direction. Exact fixture names and helper boundaries can be settled in the implementation plan without changing the architecture.
